לפני שמתחילים

לפני שמתחיליםבדיקת מערכת (שקף 7)
בדיקת מערכת, 3 דקות:
1. פתחו את Claude Code Desktop. השם שלכם מופיע? אתם מחוברים.
2. פתחו את VS Code, ואז את לוח Claude Code בצד, ושלחו "שלום".
קיבלתם תשובה בשניהם? כתבו בצ׳אט: מוכן ✅
נדרש מנוי Claude Pro ומעלה. Claude Code לא זמין בחשבון החינמי.
לפני שמתחיליםהכנה למעבדה: תיקיית עבודה (שקף 47)
הכנה לתרגול:
1. צרו תיקייה בשם technion-ai ובתוכה תיקייה בשם courses
2. הורידו את הסילבוסים של הסמסטר הנוכחי ושמרו בתוך courses/
3. פתחו את technion-ai ב-Claude Code Desktop (Open Folder) או בלוח Claude Code ב-VS Code

הדגמות

הדגמהתוכנית לימוד בארבעה רכיבים (שקף 31)
בנה לי תוכנית לימוד ל-6 השבועות עד המבחנים (מטרה).
השתמש בסילבוסים בתיקיית courses/ (הקשר).
יש לי 3 שעות ביום, בלי שישי (גבולות).
שמור טבלה שבועית בקובץ study-plan.md (פורמט).
הדגמה בזמן אמת. דוגמה לבקשה טובה: מטרה, הקשר, גבולות, פורמט.
הדגמהאפליקציית טריוויה (שקף 37)
צור קובץ HTML אחד בשם trivia.html בתיקייה הזאת.
זה צריך להיות חידון טריוויה בידע כללי עם 10 שאלות,
שחושף את התשובה בלחיצה. עיצוב נקי ומודרני, אנימציות חלקות.
HTML, CSS ו-JavaScript בלבד בקובץ אחד, בלי תלויות חיצוניות.
בקשה אחת בלוח Claude Code. כ-30 שניות לקובץ עובד.

/exit
מעבדה 1.3שיכיר אתכם (שקף 41)
תסתכל על הקבצים בתיקייה הזאת. הצג את עצמך לפי מה שאתה רואה,
ותגיד לי איזה סוג של אדם אתה חושב שאני לפי מה שיש כאן.
לפני כן: שמים בתיקייה 3–5 קבצי טקסט קטנים, ולא חומר רגיש.
מעבדה 1.4כלי לימוד (שקף 43)
צור קובץ HTML אחד בשם study-tool.html בתיקייה הזאת.
זה צריך להיות [FORMAT] בנושא [TOPIC].
עיצוב נקי ומודרני, קל לשימוש במחשב.
HTML, CSS ו-JavaScript בלבד בקובץ אחד, בלי תלויות חיצוניות.
תבנית: מחליפים [FORMAT] (כרטיסיות, טיימר פומודורו, תרגול אוצר מילים או חידון אמריקאי) ו-[TOPIC] (נושא מקורס שלכם).
מעבדה 1.5משפרים את הכלי (שקף 44)
שנה את study-tool.html כך ש-[התוספת שלכם]
תבנית. רעיונות: מצב כהה, מונה ניקוד, כפתור איפוס/ערבוב, צליל בהיפוך כרטיס, גופן גדול יותר בנייד.

סדנה

סדנהבקשה ראשונה בתיקיית העבודה (שקף 47)
מה יש בתיקייה הזו? תני לי טבלה של הקורסים, המרצים ומועדי המבחנים
אחר כך עוברים ל-Plan Mode (Shift+Tab) ומדביקים את הבקשה הבאה.
סדנהתוכנית לימוד אישית (שקף 48)
בנה לי תוכנית לימוד עד סוף הסמסטר.
השתמש בכל הסילבוסים בתיקיית courses/.
יש לי [__] שעות לימוד ביום, ואני לא לומד/ת ב-[__].
תן משקל גבוה יותר לקורסים עם מבחן מוקדם יותר.
שמור טבלה שבועית בקובץ study-plan.md בתיקייה הראשית.
תבנית: ממלאים שעות ביום, ואת היום שבו לא לומדים. סיימתם כש: study-plan.md קיים ואתם מזהים בו את המבחנים שלכם.
