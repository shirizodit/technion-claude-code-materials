שלושה חלקים: מתי, על מה, מה לעשות

settings.json{ "hooks": { "PreToolUse": [ { "matcher": "Edit|Write", "hooks": [ { "type": "command", "command": "..." } ] } ] } }
PreToolUseמתי: האירוע. כאן, רגע לפני שימוש בכלי
matcherעל מה: על אילו כלים זה חל. כאן עריכה או כתיבת קובץ
commandמה: הפקודה שרצה

⚡ ההגדרה נשמרת בקובץ ההגדרות: .claude/settings.json לפרויקט הזה, או ~/.claude/settings.json לכל הפרויקטים.

⏱ כ-3 דק׳

  • שלושה חלקים: אירוע (PreToolUse), סינון (matcher), פקודה (command). רוב ההוקים הם בדיוק זה.
  • matcher ריק פירושו כל המופעים של האירוע. Edit|Write פירושו רק כלי עריכה או כתיבה.
  • שתי כתובות לקובץ ההגדרות, כמו ב-Skills וב-agents: בתיקייה (לפרויקט) או אצלכם אישית.
  • חשוב: לא צריך לזכור את המבנה. אפשר לבקש מ-Claude לכתוב את ההוק (עושים זאת בשקף הבא), ורק לקרוא אותו.

התראה כש-Claude מחכה לכם

  1. מדביקים בחלונית של Claude Code את הבקשה למטה
  2. Claude כותב את ההוק לקובץ ההגדרות, ועוצר. קוראים מה נכתב
  3. מקלידים /hooks. ההוק מופיע ברשימה תחת Notification
הוסף לקובץ ההגדרות האישי שלי (~/.claude/settings.json) הוק על האירוע Notification, שמציג התראה על המסך בנוסח "Claude Code needs your attention". המחשב שלי: Mac. אל תמחק הגדרות קיימות, ועצור כדי שאראה מה כתבת.

⚡ ב-Windows או ב-Linux? פשוט כתבו בבקשה את מערכת ההפעלה שלכם, ו-Claude יתאים את הפקודה.

⏱ כ-4 דק׳

  • זה ההוק הראשון: הכי פשוט וכבר שימושי. מדגימים חי.
  • הדרך הבטוחה למי שלא רגיל ל-JSON: לבקש מ-Claude לכתוב את ההוק. התיעוד עצמו אומר שאפשר לבקש מ-Claude לכתוב אותו.
  • ״אל תמחק הגדרות קיימות״: חשוב. אם כבר יש קובץ settings.json, ההוק נוסף ולא מחליף. אם ההגדרות קיימות, מוסיפים את Notification בתוך אובייקט hooks הקיים.
  • /hooks פותח את דפדפן ההוקים. ככה מוודאים שההוק נקלט, בלי לחכות לאירוע.
  • אם אין התראה ב-Mac: בפעם הראשונה ייתכן שצריך לאשר התראות עבור Script Editor בהגדרות המערכת (System Settings > Notifications). [לוודא במחשב ההדגמה]
  • נסו עכשיו: אחרי שההוק מופיע ב-/hooks, עוברים לשקף הבא לבדיקה.

--allowedToolsאילו כלים מותרים בלי לשאול. כאן רק קריאה
