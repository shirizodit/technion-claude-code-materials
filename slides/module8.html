שלושה חלקים: מתי, על מה, מה לעשות

settings.json{ "hooks": { "PreToolUse": [ { "matcher": "Edit|Write", "hooks": [ { "type": "command", "command": "..." } ] } ] } }

matcherעל מה: על אילו כלים זה חל. כאן עריכה או כתיבת קובץ

⚡ ההגדרה נשמרת בקובץ ההגדרות: .claude/settings.json לפרויקט הזה, או ~/.claude/settings.json לכל הפרויקטים.

  1. מדביקים בחלונית של Claude Code את הבקשה למטה
  2. Claude כותב את ההוק לקובץ ההגדרות, ועוצר. קוראים מה נכתב

הוסף לקובץ ההגדרות האישי שלי (~/.claude/settings.json) הוק על האירוע Notification, שמציג התראה על המסך בנוסח "Claude Code needs your attention". המחשב שלי: Mac. אל תמחק הגדרות קיימות, ועצור כדי שאראה מה כתבת.

⚡ ב-Windows או ב-Linux? פשוט כתבו בבקשה את מערכת ההפעלה שלכם, ו-Claude יתאים את הפקודה.

מודול 8 · בונים הוק 2 · שלב 1

שומר: אסור לגעת בקבצי המקור

.claude/hooks/protect-notes.sh#!/bin/bash INPUT=$(cat) FILE=$(echo "$INPUT" | jq -r \ '.tool_input.file_path // empty') if [[ "$FILE" == *"/notes/"* ]]; then echo "Blocked: notes/ is read-only" >&2 exit 2 fi exit 0
מה הוא עושהקורא את שם הקובץ ש-Claude עומד לערוך
אם הקובץ בתוך notes/כותב הסבר וחוזר עם קוד 2: חסימה
אחרתקוד 0: ממשיכים כרגיל

⚡ הסקריפט קורא את הקלט עם jq. אם חסר לכם: brew install jq. אפשר לבקש מ-Claude להתקין ולהסביר.

מודול 8 · בונים הוק 2 · שלב 2

יוצרים ובודקים

  2. קוראים את שניהם. מאשרים להפעיל את הסקריפט (chmod +x)

צור הוק PreToolUse על Edit ו-Write בהגדרות הפרויקט (.claude/settings.json). הוא מריץ סקריפט .claude/hooks/protect-notes.sh שחוסם (קוד יציאה 2) כל עריכה של קובץ שנמצא בתיקייה notes/, עם הודעה "Blocked: notes/ is read-only". הסקריפט קורא את הנתיב עם jq. הפוך אותו להרצה ועצור כדי שאראה.
✅ סיימתם כש: הבקשה לערוך קובץ ב-notes/ נחסמה, ו-Claude הסביר לכם למה.
