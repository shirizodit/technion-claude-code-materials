איך מעבירים

כמו השליח.

שרת מקומי

stdio: תקשורת ישירה על המחשב, מהירה, בלי רשת. לא צריך הרשאה.

שרת מרוחק

Streamable HTTP: בקשות ברשת, אפשר לשרת הרבה משתמשים. נכנסים פעם אחת עם הרשמה בדפדפן (OAuth) או מפתח.

מודול 6 · זהירות

מחברים רק שרתים שסומכים עליהם

  • שרת מחובר יכול לפעול עם ההרשאות שלכם: לקרוא קבצים, לשלוח מייל, לפרסם הודעות
  • הוא גם מביא תוכן מבחוץ (דף אינטרנט, מסמך) שעלול לנסות לבלבל את Claude. זה נקרא prompt injection
  • ההגנה: שרתים ממקור אמין, עדיפות לפתוחים ומוכרים
  • וההרגל מ-Module 3 נשאר: Claude שואל לפני שהוא פועל
⚠ בכיתה: לא מחברים חשבון עבודה או מייל עם מידע רגיש. לתרגול: חשבון אישי ריק, או תוכן שלא מפריע לכם שייחשף.

מוסיפים שרת: חיבור ובדיקה

צעד 1. בטרמינל (לא בתוך שיחה) מוסיפים את שרת המסמכים של Claude Code. חינמי, בלי הרשמה:

claude mcp add --transport http claude-code-docs https://code.claude.com/docs/mcp

צעד 2. בודקים שהוא מחובר, ומחפשים ✓ Connected:

claude mcp list

השם claude-code-docs הוא בחירה שלכם. ברירת המחדל: השרת נוסף לפרויקט הנוכחי; עם --scope user הוא זמין בכל מקום.

Live Demo

מוסיפים שרת: רואים מה הוא יודע ומשתמשים

צעד 3. בתוך שיחה עם Claude, מקלידים /mcp ובוחרים את השרת. רואים את רשימת הכלים שלו:

/mcp

צעד 4. שואלים ומאשרים את הכלי בפעם הראשונה:

Use the claude-code-docs server to look up what MCP_TIMEOUT does.

התשובה מסומנת בשם השרת: הוכחה שהיא הגיעה דרכו. אם מופיע ! Needs authentication: /mcp, בוחרים שרת, Authenticate, מתחברים בדפדפן. לשרת הזה לא צריך.
