עם MCP

מחברים את האפליקציות שלכם ל-Claude, ואז הוא יכול לקרוא ולפעול בהן בשבילכם.

⏱ כ-2 דק׳

  • בלי חיבור הוא לא נוגע במייל, ביומן, בקבצים או ברשת.
  • MCP הוא הדרך הסטנדרטית לחבר את האפליקציות האלה ל-Claude.
  • אחרי החיבור הוא יכול גם לפעול, לא רק לקרוא.
  • למה זה חשוב לכם: תדריך שבועי, מעקב מועדי מבחנים, סיכום מאמרים. כולם דורשים מקור חי.
מודול 6 · למה MCP

מה זה MCP‏?

Model Context Protocol

ModelAI model (Claude / others)
ContextThe information and abilities
ProtocolA standard way to communicate

A standardized way for LLMs to communicate with other programs.

Examples:Google DriveGmailGoogle SlidesGoogle Sheets…

⏱ כ-3 דק׳

  • מפרקים את השם לשלוש מילים. לוחצים כדי לחשוף כל אחת: Model, Context, Protocol.
  • המשפט המסכם: דרך סטנדרטית ל-LLM לדבר עם תוכנות אחרות. דוגמאות: Drive, Gmail, Slides, Sheets.
  • שם: Model Context Protocol. Model זה Claude, Context זה המידע והיכולות, Protocol זו שפה משותפת.
  • לא צריך לזכור את הקיצור. צריך לזכור את הרעיון: דרך אחת וסטנדרטית לחבר כלים.
  • למה זה חשוב לכם: בלי תוכנה מיוחדת לכל אפליקציה. מחברים פעם אחת ואז שואלים בעברית.

מה אומרים

כמו תוכן המכתב.

איך מעבירים

הדרך שבה ההודעות מגיעות. תלויה במקום שבו השרת יושב.

כמו השליח.

שרת מקומי

stdio: תקשורת ישירה על המחשב, מהירה, בלי רשת. לא צריך הרשאה.

שרת מרוחק

Streamable HTTP: בקשות ברשת, אפשר לשרת הרבה משתמשים. נכנסים פעם אחת עם הרשמה בדפדפן (OAuth) או מפתח.

⏱ כ-3 דק׳

  • שתי שכבות: שכבת הנתונים (מה אומרים) ושכבת ההעברה (איך מעבירים). אותה שפה, שתי דרכי העברה.
  • מקומי: stdio, ישיר על המחשב. מרוחק: HTTP ברשת, עם הרשמה (OAuth) או מפתח.
  • זה מסביר למה יומן וג׳ימייל דורשים התחברות ושרת הקבצים לא.

מוסיפים שרת: חיבור ובדיקה

צעד 1. בטרמינל (לא בתוך שיחה) מוסיפים את שרת המסמכים של Claude Code. חינמי, בלי הרשמה:

claude mcp add --transport http claude-code-docs https://code.claude.com/docs/mcp

צעד 2. בודקים שהוא מחובר, ומחפשים ✓ Connected:

claude mcp list

השם claude-code-docs הוא בחירה שלכם. ברירת המחדל: השרת נוסף לפרויקט הנוכחי; עם --scope user הוא זמין בכל מקום.

⏱ כ-4 דק׳

  • דמו חי, בטרמינל המשולב של האפליקציה או של VS Code.
  • מריצים את הפקודה בדיוק כפי שהיא. השם claude-code-docs הוא בחירה שלנו.
  • claude mcp list: מחפשים ✓ Connected.
