רעיונות מרכזיים

מה כדאי לזכור

צ׳אט עונה. סוכן עושה.

סוכן = מודל (המוח) + כלים (קורא וכותב קבצים) + זיכרון + משימות. הוא חושב, פועל, בודק, וחוזר עד שהמשימה גמורה.

התיקייה היא העולם של Claude

מה שלא בתיקייה שפתחתם, הוא לא ימצא לבד. תיקייה מסודרת נותנת תשובות טובות יותר. מומלץ תיקייה אחת לכל "עולם": לימודים, תזה, מעבדה.

מודול 2

איך Skill בנוי מבפנים

Skill הוא תיקייה עם קובץ אחד חובה: SKILL.md (באותיות גדולות, בדיוק ככה). שם התיקייה הופך לפקודה: התיקייה my-skill נותנת את הפקודה /my-skill. כל השאר (תוכניות, דוגמאות, חומרי עזר) אופציונלי. אין כאן קסם: אלה קבצים רגילים שאפשר לפתוח, לערוך ולשלוח לחבר.

my-skill/my-skill/ ├── SKILL.md ← חובה ├── scripts/ ← אופציונלי ├── reference.md └── examples/

תקן פתוח

MCP הוא תקן פתוח (open-source) לחיבור אפליקציות AI למערכות חיצוניות: קבצים, מסדי נתונים, כלי חיפוש ועוד. Claude, ChatGPT, VS Code ו-Cursor תומכים בו, כך שבונים חיבור פעם אחת והוא עובד בכמה אפליקציות.

בונים צוות של שני סוכנים

המטרה: שני סוכנים שרצים בזה אחר זה על משימה אחת, על חומר אמיתי שלכם. החוקר קורא ומחפש ולא כותב. הבונה מקבל את הסיכום ויוצר את הפלט. רק סיכום קצר עובר ביניהם, והקריאה הרועשת נשארת אצל החוקר.

החוזה בין שניהם, במשפט אחד: החוקר קורא את X ומחזיר Y. הבונה קורא את Y ויוצר את Z. אצל נועה: החוקר קורא את סיכומי ההרצאות ומחזיר את עשרת הנושאים החשובים, והבונה יוצר מהם דף סיכום למבחן.

סוכןכלים
חוקרRead, Glob, Grep
בונהRead, Write
רק אם מריץ סקריפטBash

בחרו חומר: סיכומי הרצאות לדף למבחן (זה מה שבתיקייה notes/), מאמרים לסקירה קצרה, או טיוטה לביקורת. אם בוחרים מאמרים או טיוטה, צריך קודם ליצור את הקבצים (papers/ או draft.md); ראו את התיבה בהמשך.

בונים את שני הסוכנים במכה אחת:

צעדים 2–4 · יצירת החוקר והבונהצור שני סוכני-משנה בתיקייה .claude/agents/: 1. researcher: קורא את הקבצים בתיקייה notes/ ומחזיר רשימה קצרה של הנושאים החשובים, ליד כל אחד שם הקובץ. כלים: Read, Glob, Grep בלבד. לא ממציא ולא עורך. 2. builder: מקבל את הרשימה ויוצר קובץ summary.html אחד, עצמאי. כלים: Read, Write. עונה בעברית. כתוב לכל אחד תיאור חד שמסביר מתי להשתמש בו, ועצור כדי שאראה את שני הקבצים.

חומר אחר? מחליפים את notes/ ואת שמות הסוכנים (למשל papers/, ו-paper-scout ו-slide-writer).

כך אמורים להיראות שני הקבצים (בערך):

.claude/agents/researcher.md--- name: researcher description: Reads my course notes or papers and returns the key points. Use first, before any writing. tools: Read, Glob, Grep --- Read only. Return a short list of key topics, each with the source file. Never invent. Never edit.
.claude/agents/builder.md--- name: builder description: Builds summary.html from the researcher's key points. Use after the researcher is done. tools: Read, Write --- Create one self-contained summary.html from the points you are given. Answer in Hebrew.

שימו לב: לחוקר אין Write. זה מה שהופך אותו לבטוח. ב-"Answer in Hebrew" הפלט יוצא בעברית גם כשהקובץ באנגלית.

מפעילים את שניהם בבקשה אחת:

צעד 5 · הרצההפעל שני סוכני-משנה לפי הסדר: 1. השתמש בסוכן researcher כדי לקרוא את כל הקבצים בתיקייה notes/ ולמצוא את הנושאים החשובים לקראת המבחן. 2. אחר כך השתמש בסוכן builder כדי להפוך את הרשימה לדף summary.html אחד. בין השניים, הראה לי את הרשימה של ה-researcher.

הבקשה עושה שלושה דברים: שלב 1 החוקר קורא ומסכם, עצירה שבה אתם רואים את הרשימה (שער קטן), ושלב 2 הבונה יוצר את הדף. אפשר למחוק את שורת העצירה, אבל בפעם הראשונה שווה לראות מה החוקר מצא.

אין לכם מאמרים או טיוטה? בקשו מ-Claude ליצור. (רק אם בחרתם באפשרות הזאת; בשביל התרגיל עם notes/ אין צורך.) תארו במילים שלכם, למשל: "צור בתיקייה papers/ שלושה מאמרים קצרים לדוגמה על אותו נושא בהנדסה", או "צור קובץ draft.md עם טיוטה קצרה של סעיף בעבודה". אחרי זה החליפו בבקשות notes/ ב-papers/.
